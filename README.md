# Heimatkirche Jahresplan 2027

Vorlage für den Kirchengemeinderat der Ev. Verbundkirchengemeinde Dornstetten: fünf Konzepte, wie die Heimatkirche 2027 in Aach Platz findet, ohne mit der Jungen Kirche zu kollidieren. Mit Randbedingungen, Prüfung der Pfarrer-Einteilung und Jahresplan.

Die Seite (`index.html`) ist eigenständig und wird über GitHub Pages ausgeliefert.
